# Prompts utilizados no desenvolvimento

## Prompt para criação da estrutura do frontend feito por Luis Gustavo Pagliarini de Sousa

"Crie a estrutura inicial do frontend em React para uma rede social simples, com páginas de Home, Login e Cadastro, usando React Router DOM, React Hook Form e Axios."

## Prompt para criação do contexto de autenticação feito por Luis Gustavo Pagliarini de Sousa

"Crie um AuthContext em React para controlar cadastro, login, logout, usuário logado e armazenamento do token no localStorage."

## Prompt para design inspirado em rede social antiga feito por Luis Gustavo Pagliarini de Sousa

"Melhore o visual da aplicação usando como inspiração o estilo de redes sociais antigas, especialmente o Twitter de 2010-2011, sem copiar marca oficial."

## Prompt para integração do frontend com backend feito por Luis Gustavo Pagliarini de Sousa

"Conecte o frontend React com o backend Express, usando as rotas /auth/register, /auth/login, /posts e /favorites/:id para cadastro, login, listagem de posts, publicação e curtidas."

## Prompt para criação do backend feito por Willian Peres Assunção

"Crie um backend em Node.js com Express e SQLite para uma rede social simples, contendo autenticação com cadastro e login, senha com hash, JWT, tabela de usuários, posts e favoritos."

## Prompt para criação das rotas de posts e curtidas feito por Willian Peres Assunção

"Crie rotas no backend para listar posts, criar posts autenticados, curtir e descurtir posts usando uma tabela de favoritos no SQLite."
